# Core Extraction & Spring Boot Adapters — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> subagent-driven-development (recommended) or executing-plans to
> implement this plan task-by-task. Each task follows TDD
> (test-driven-development) and uses ide-tooling for structural
> editing. Steps use checkbox (`- [ ]`) syntax for tracking.

**Focal issue:** casehubio/casehub-desiredstate#139 — Core extraction and Spring Boot adapters
**Issue group:** casehubio/casehub-desiredstate#139, casehubio/parent#515

**Goal:** Extract framework-neutral core modules from casehub-desiredstate
and add Spring Boot auto-configuration so the runtime, graph declaration
surfaces, and persistence can be embedded in both Quarkus and Spring Boot.

**Architecture:** Follow the established platform pattern — POJOs with
constructor injection in -core modules, `List<T>` for `Instance<T>`,
`Consumer<T>` for `Event<T>`. Quarkus modules slim to CDI bridges +
`@Produces` beans. Spring auto-configs generated by spring-generator
where possible, hand-written for surface-specific scanning logic.

**Tech Stack:** Java 21+, Maven, Quarkus (existing), Spring Boot 3.x
(new), Jandex, Jackson, JPA/Hibernate

## Global Constraints

- `runtime-core/` must have zero CDI, zero Spring, zero Quarkus imports
- `annotations/core/`, `yaml/core/`, `ts-dsl/core/` must have zero CDI/Spring imports (Jandex is allowed — it's a build/scan tool)
- All new -core modules require jandex-maven-plugin for spring-generator scanning
- groupId: `io.casehub`, parent: `casehub-desiredstate-parent`
- Existing Quarkus tests must pass after each batch (regression gate)
- All module names follow `casehub-desiredstate-<name>` convention

- [ ] **Step 6: Create RuntimeBeans.java in runtime/**

Create `runtime/src/main/java/io/casehub/desiredstate/runtime/RuntimeBeans.java`:

```java
package io.casehub.desiredstate.runtime;

import io.casehub.desiredstate.api.*;
import io.cloudevents.CloudEvent;
import jakarta.enterprise.context.ApplicationScoped;
import jakarta.enterprise.event.Event;
import jakarta.enterprise.inject.Instance;
import jakarta.enterprise.inject.Produces;
import io.quarkus.arc.DefaultBean;

@ApplicationScoped
public class RuntimeBeans {

    @Produces @ApplicationScoped
    public TransitionPlanner transitionPlanner(
            NodeProvisionerRouter router,
            ReconciliationStateStore stateStore,
            FaultCountStore faultCountStore) {
        return new TransitionPlanner(router, stateStore, faultCountStore);
    }

    @Produces @ApplicationScoped
    public FaultPolicyEngine faultPolicyEngine(
            Instance<FaultPolicy> policies,
            FaultCountStore store) {
        return new FaultPolicyEngine(policies.stream().toList(), store);
    }

    @Produces @ApplicationScoped
    public SituationRecompilerEngine situationRecompilerEngine(
            Instance<io.casehub.desiredstate.api.SituationRecompiler> recompilers) {
        return new SituationRecompilerEngine(recompilers.stream().toList());
    }

    @Produces @ApplicationScoped
    public CbrFaultPolicy cbrFaultPolicy(
            FaultCountStore faultCountStore,
            io.casehub.platform.api.memory.CaseMemoryStore memoryStore,
            io.casehub.platform.api.preferences.PreferenceProvider preferenceProvider,
            ReconciliationStateStore reconciliationStateStore) {
        return new CbrFaultPolicy(faultCountStore, memoryStore,
                preferenceProvider, reconciliationStateStore);
    }

    @Produces @ApplicationScoped
    public CbrSituationRecompiler cbrSituationRecompiler(
            FaultCountStore faultCountStore,
            io.casehub.platform.api.memory.CaseMemoryStore memoryStore,
            io.casehub.platform.api.preferences.PreferenceProvider preferenceProvider,
            ReconciliationStateStore reconciliationStateStore) {
        return new CbrSituationRecompiler(faultCountStore, memoryStore,
                preferenceProvider, reconciliationStateStore);
    }

    @Produces @DefaultBean @ApplicationScoped
    public ReconciliationLoop reconciliationLoop(
            TransitionPlanner planner,
            TransitionExecutor executor,
            ActualStateAdapterRouter actualStateRouter,
            FaultPolicyEngine faultPolicyEngine,
            MergedEventSource mergedEventSource,
            NodeProvisionerRouter router,
            Event<CloudEvent> cloudEventSink,
            Instance<GlobalReconciliationListener> listeners,
            CbrProposalTracker cbrTracker,
            ReconciliationStateStore stateStore) {
        return new ReconciliationLoop(planner, executor, actualStateRouter,
                faultPolicyEngine, mergedEventSource, router,
                ReconciliationLoop.DEFAULT_DEBOUNCE, null,
                cloudEventSink::fire, cbrTracker,
                listeners.stream().toList(), stateStore);
    }

    @Produces @DefaultBean @ApplicationScoped
    public SimpleTransitionExecutor simpleTransitionExecutor(
            NodeProvisionerRouter router,
            ActualStateAdapterRouter actualStateRouter,
            FaultCountStore faultCountStore,
            Instance<ReconciliationListener> listeners) {
        return new SimpleTransitionExecutor(router, actualStateRouter,
                faultCountStore, listeners.stream().toList());
    }

    @Produces @DefaultBean @ApplicationScoped
    public DefaultFaultCountStore defaultFaultCountStore() {
        return new DefaultFaultCountStore();
    }

    @Produces @DefaultBean @ApplicationScoped
    public DefaultReconciliationStateStore defaultReconciliationStateStore() {
        return new DefaultReconciliationStateStore();
    }
}
```

```java
@AutoConfiguration
@ConditionalOnClass(GoalCompilerFactory.class)
public class DesiredStateAnnotationsAutoConfiguration
        implements SmartInitializingSingleton {

    private final GenericApplicationContext context;

    public DesiredStateAnnotationsAutoConfiguration(GenericApplicationContext ctx) {
        this.context = ctx;
    }

    @Override
    public void afterSingletonsInstantiated() {
        List<IndexView> indexes = loadJandexIndexes();
        CompositeIndex composite = CompositeIndex.create(indexes);

        List<GraphDescriptor> graphs = DescriptorScanner.scanGraphs(composite);
        DescriptorScanner.validate(graphs);

        for (GraphDescriptor gd : graphs) {
            GoalCompiler<?> compiler = GoalCompilerFactory.create(gd);
            String beanName = "goalCompiler_" + gd.namespace() + "_" + gd.name();
            context.registerBean(beanName, GoalCompiler.class, () -> compiler);
        }

        List<FaultPolicyDescriptor> policies = DescriptorScanner.scanFaultPolicies(composite);
        for (FaultPolicyDescriptor fpd : policies) {
            ThresholdFaultPolicy policy = FaultPolicyFactory.create(fpd, fpd.sourceClassName());
            String beanName = "faultPolicy_" + fpd.namespace();
            context.registerBean(beanName, ThresholdFaultPolicy.class, () -> policy);
        }
    }

    private List<IndexView> loadJandexIndexes() {
        List<IndexView> indexes = new ArrayList<>();
        try {
            Enumeration<URL> resources = Thread.currentThread()
                    .getContextClassLoader()
                    .getResources("META-INF/jandex.idx");
            while (resources.hasMoreElements()) {
                try (InputStream is = resources.nextElement().openStream()) {
                    indexes.add(new IndexReader(is).read());
                }
            }
        } catch (IOException e) {
            throw new IllegalStateException("Failed to load Jandex indexes", e);
        }
        return indexes;
    }
}
```
